# Final ACL Bootstrap

Локальный кандидат для независимой приёмки. Публикуемый набор содержит девять текстовых файлов из SHA256SUMS. Образы, .deb, журналы и diff в него не входят.

Host получает официальный Ubuntu Noble release-20261017 amd64, проверяет подпись SHA256SUMS Ubuntu cloud keyring и требует точный SHA‑256 04e8f2461a16a44e78a370284471f29616cdd9baf1893df25807b71f985b6c94. qemu-img подтверждает qcow2 без backing/data files. Недоступность закреплённого образа приводит к отказу.

APT использует только заданные официальные источники Ubuntu и подписанные индексы, останавливается при ошибке обновления и скачивает acl:amd64=2.3.2-1build1.1. Host сверяет версию, архитектуру, хеш архива и полные Depends/Pre-Depends с метаданными. Каждая группа зависимостей проверяется с учётом альтернатив и ограничений версии через dpkg --compare-versions по пакетному манифесту выбранного образа. Неизвестный синтаксис блокируется. Манифест служит предварительной проверкой. Перед установкой гость независимо проверяет фактическое состояние пакетов через dpkg-query.

Единственный read-only ISO содержит пять файлов: acl.deb, meta-data, network-config, neutral.txt и user-data. Лимит ISO составляет 2 МиБ. Host перечитывает все файлы через isoinfo и сверяет байты и инвентарь. Хеш acl встраивается в user-data. Полный SHA ISO и канонический манифест всех пяти файлов сверяются с host при приёмке serial.

NETWORK и DEVICES выполняются до установки пакета. Далее гость проверяет ISO, параметры ro,nodev,nosuid,noexec и EROFS для существующих файлов и новой записи. ACL_BOOTSTRAP сверяет sha256 и метаданные архива, архитектуру amd64, точную libacl1 и полные зависимости через dpkg-query и dpkg --compare-versions. Локальный dpkg устанавливает единственный acl.deb на гостевой диск без скачивания. Неуспех или несовместимость даёт ISO_DIAG_FAIL ACL_BOOTSTRAP. Затем проверяются getfacl, полный TOOLS, visudo, IDENTITY и SHUTDOWN. Вызов getfacl -cp /run подтверждает работоспособность. Проверку отсутствия расширенных ACL выполняет отдельно будущий A–D v1.2.

Гость имеет 2 vCPU, 2048 МиБ RAM, один RW qcow2, один RO ISO, KVM без fallback. NIC, host sockets, guest agent и shared folders отсутствуют. Супервизор, его wait4, TERM/KILL, serial 8 МиБ, rm/rmdir и проверки обоих inode побайтово сохранены относительно входного кандидата. До 1197 с требуется своевременный rmdir, до 1198 с его остановка и сбор, до 1199 с резерв подтверждения. Успешное решение принимается строго до 1200 с. Job timeout составляет 30 минут. Синхронные операции после решения могут задержать фактический выход процесса.

Полные сырые stdout/stderr подготовки и serial не публикуются. Парсер принимает только фиксированные маркеры. До публикации требуется независимый статический review и отдельное разрешение владельца на конкретный комплект и один запуск. A–D v1.2 остаются NOT_RUN.

Реальные APT authentication/download, установка Debian-пакета в госте, сборка ISO, Linux DAC, mountinfo, O_PATH, GNU rm/rmdir, st_nlink обоих каталогов, EROFS и KVM остаются NOT_RUN. Локальные тесты используют имитации внешних инструментов и платформенного поведения macOS.
